# Happy赖 IP 动画 · 工作台4步法 · 分镜脚本

**形态**：不露脸 IP 动画（分镜绘本风）—— Happy赖 小人当主角，开口讲内容
**总时长**：约 50–60 秒
**画风**：温暖淡彩手绘（与你立绘、`happy-illustrator` 技能一致；低马尾 / 圆框眼镜 / 红格子+卡其）
**配音**：`voiceover-cn` 公共女声（晓晓 `XiaoxiaoNeural` + `cheerful` 轻松风格）
**BGM**：剪映搜"轻快手绘 / 治愈vlog"，音量压到 20% 别盖过人声
**尺寸**：竖屏 1080×1920

## 画外音完整稿（一次生成用）

> 复制下面整段存成 `口播稿.md`，直接喂给 `voiceover-cn` 出 mp3。

朋友，不想露脸又想做视频？看我的 Happy赖 工作台怎么搭~
第一步，想清楚要它干啥——先列三个真用得上的，别贪多，这是新手最容易翻车的地方。
第二步，跟你的 AI 搭子说人话："帮我做个手机电脑都能用的"，它帮你生成，你一行代码都不用碰。
第三步，让它一键发到网上，丢给你一个链接，手机点开就能用。
第四步，把链接加到手机主屏幕，离线也能用，跟个 APP 一样。
从"我也想要"到每天用它，就一个下午。想看手把手教程，全网搜 Happy赖 就行。拜拜~
