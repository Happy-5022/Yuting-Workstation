第 3 步：把网页发到网上（部署）

「部署」翻译过来就是：把做好的网页文件放到大家能访问的网址上

🅰️ 选法 A：省事版（推荐零基础）

直接跟 AI 搭子说：「帮我把这个发布到网上，给我一个能打开的链接。」

它帮你处理好，回头丢给你一个网址。手机点开就能用。

🅱️ 选法 B：自己掌控版（GitHub Pages）

想要网页文件完全归自己管、有自己的网址？用 GitHub Pages，免费。

具体步骤见教程附录，命令复制粘贴就能成。卡住别慌，回头问 AI。

第 4 步：装到手机主屏，离线也能用

📱 三步装到主屏

① 手机浏览器打开那个网址
② 点右上角「分享」→「添加到主屏幕」
③ 桌面多了一个图标，点开就是你的工作台 ✨

📴 没网也能用

数据存在你手机里，不依赖网络，随时能打开。

⚠️ 更新别删图标

iPhone 更新版本：划掉后台网页重新打开。别删主屏图标，删了数据一起没。

附录 · 想自己掌控？用 GitHub Pages 部署（简易版）

让网页真正属于你：免费、网址干净、还能离线装进手机主屏

📋 5 步走完（用 Git Bash）

① 注册 GitHub，新建仓库，名字用 你的用户名.github.io
② 在网页文件夹上右键 →「Git Bash Here」
③ 依次输入下面几行（每行一回车）：
git init
git add .
git commit -m "我的工作台"
git branch -M main
git remote add origin 仓库地址
git push -u origin main
④ 密码栏填「个人访问令牌 PAT」（一串字符，不是登录密码；粘贴时不显示属正常）
⑤ 等几分钟，打开 https://你的用户名.github.io 就看到啦

💡 两个坑别踩

① 别用 GitHub 网页「Upload files」传文件夹——会丢子文件，页面变白板。用 Git Bash 整目录推。

② 改完重新 git add . / commit / push，手机把网页划掉重开就更新（别删主屏图标，会丢数据）。
