# 《给自己搭一个个人专属工作台》录屏讲话稿

> 用途：对着 `个人工作台搭建教程.html` 录屏，边翻页边念这段画外音，发给朋友看。
> 形式：不露脸、纯录屏 + 画外音（念下面的话就行，几乎不用剪）。
> 总时长：约 6–7 分钟（含附录），语速放慢、像跟朋友聊天最自然。

---

## 🎬 录屏前的小准备

1. 用浏览器打开 `个人工作台搭建教程.html`，按 **F11** 全屏（录出来更干净）。
2. 开系统录屏：
   - Windows：按 `Win + G` 召唤 Xbox 录屏；
   - Mac：用 QuickTime 或剪映录屏。
3. 翻页就用键盘 **→**（下一页）、**←**（上一页），念完一页就翻下一页。
4. 录完丢进剪映 → 自动字幕 → 哪里念错了单独重念那页补上即可，不用精剪。

## 第 5 页 · 第 1 步：想清楚要它干啥（⏱ 约 35 秒）

**翻页时机**：说完「后面用顺了随时加」后按 →

> 第一步，也是最重要的一步——先想清楚你要它帮你干啥。
> 新手最容易翻车的地方，就是一上来就要一百个功能，结果半天搭不起来，直接放弃。

> 我总忘记今天该干嘛 → 每日待办；
> 想养成写感恩日记的习惯 → 今日感恩；
> 刷到好句子想存 → 收藏句子；
> 想磨耳朵学英语 → 每日英语；
> 做自媒体没灵感 → 灵感收集。
> 你先列三个就够，后面用顺了随时加。

## 第 7 页 · 第 3 步：把网页发到网上（⏱ 约 30 秒）

**画面**：左图「发到网上」+ 右侧两张卡（选法 A / 选法 B）
**翻页时机**：说完「回头问 AI」后按 →

> 第三步，把网页发到网上，也就是"部署"。这词听着唬人，其实就是把做好的网页文件放到大家能访问的网址上。
> 两种选法：
> 选法 A 省事版，推荐零基础——直接跟 AI 搭子说"帮我把这个发布到网上，给我一个能打开的链接"，它帮你处理好，回头丢给你一个网址，手机点开就能用。
> 选法 B 自己掌控版，用 GitHub Pages，免费，网页文件完全归自己管、有自己的网址。具体步骤教程附录里都有，命令复制粘贴就能成，卡住别慌，回头问 AI。

## 第 8 页 · 第 4 步：装到手机主屏（⏱ 约 30 秒）

**画面**：左图「装到主屏」+ 右侧三张卡（三步 / 没网也能用 / 更新别删图标）
**翻页时机**：说完「删了数据就一起没了」后按 →

> 第四步，装到手机主屏，离线也能用。这一步最爽，做完它就像个 App。
> 三步：手机浏览器打开那个网址；点右上角"分享"→"添加到主屏幕"；桌面多了一个图标，点开就是你的工作台。
> 而且没网也能用，数据存在你手机里，不依赖网络。
> 一个小提醒：iPhone 更新版本的时候，划掉后台网页重新打开就行，千万别删主屏图标，删了数据就一起没了。

## 第 12 页 · 附录：想自己掌控？用 GitHub Pages（⏱ 约 35 秒）

**画面**：左卡「5 步 Git Bash 部署」+ 右卡「两个坑别踩」
**翻页时机**：说完「是最稳的玩法」后结束录制

> 最后这个附录，是给想自己完全掌控的朋友留的。
> 你要是不想依赖 AI 一键发布、想让网页文件完全归自己管，就用 GitHub Pages，免费。
> 五步走完：注册个 GitHub，仓库名用"你的用户名.github.io"；在网页文件夹上右键开 Git Bash；照着左边命令块逐行粘贴——init、add、commit、branch、remote、push；密码栏填那个"个人访问令牌"，一串字符，粘贴时不显示是正常的，别慌；等几分钟，打开网址就看到你的工作台啦。
> 两个坑别踩：第一，别用 GitHub 网页的"Upload files"传文件夹，会丢子文件、变白板；第二，改完重新 push 之后，手机把网页划掉重开就更新，千万别删主屏图标，删了数据一起没。
> 平时用省事版就够，真想折腾、想要最稳的玩法，这套拿走不谢。
> 好啦，我是 Happy赖，分享给想偷懒但想要顺手工具的朋友。拜拜～
