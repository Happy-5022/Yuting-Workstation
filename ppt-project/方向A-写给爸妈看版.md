# 正文（长辈视角，轻松口语，写给"老姐妹老哥们"看）

你是不是也这样——

刚想跟孩子说的事，一转身就忘了。
降压药早上吃过没，自己都拿不准。
买菜清单、老姐妹的聚会，记在纸上转眼找不着。

别急，这不是你记性差，是年纪到了，脑子偶尔像旧收音机串了台。

我给你说个法子：在手机上弄个小本本，专门替你记这些。不用下载 APP，不占地方，断网也能看。

它有两个好用的：

一个是**语音记**。不想打字？对着手机说一句，它就给你写下来——买啥菜、啥时候广场舞、老姐妹约的牌局，张口就来。

一个是**每日小账**。把"几点吃药、买啥菜"写进去，一打开就看见，不用怕忘。

怎么弄？简单。让儿女帮你打开一次，点几下加到桌面，以后你点那个小图标就能用。你要是嫌麻烦，就叫孩子帮你弄，弄好你只管用。

我现在就这么做，买菜、聚会再也不漏。你也可以的。

**觉得有用，转给你的老姐妹、老哥们，大伙一起少忘点事。**

# ⚠️ 诚实提醒（发之前务必看一眼，别穿帮）

- 文章里写的 **「语音记」「每日小账」是你工作台真实存在的「语音速记」「每日计划」模块**，改名只是让老人好懂，功能对得上，子女/老人装完不会发现货不对板。
- 但你工作台**没有"自动闹钟提醒"功能**——所以文章只写"写进去一打开就看见"，**没写"到点自动响"**，实话，别自己改成自动提醒。
- "看得清"方面：工作台是手机网页，能双指放大，但**不是专门的大字模式**。文章里没承诺"大字版"，只说"手机上弄个小本本""字放大截"，安全。
- 链接用你已部署的 GitHub Pages 地址（happy-5022.github.io/Yuting-Workstation/），发之前自己先点开确认能正常打开；老人的那一步"让儿女帮打开"才是现实可行的操作路径。
