# 越南语新词发音音频 · 生成说明

适用情况：每次给工作台「越南语学习」加了新单词后，都需要生成对应的发音文件（.mp3），点「听」才会有声音。本次已把词汇从 120 个扩到约 380 个，新增的词都需要补声音。

## 为什么不能一步到位？
新词的发音是用微软越南语女声（vi-VN-HoaiMyNeural）在线录下来的 mp3。我的运行环境连不上外网、也碰不到你的电脑，所以这一步得**在你自己电脑上**做。以后每次再加新词，重跑一次脚本即可。

## 第一步：准备工具（只用做一次）
1. 装 Python：如果你电脑还没装，去 https://www.python.org/downloads/ 下载 Windows 版，安装时**务必勾选 "Add Python to PATH"**，然后一路下一步。
2. 装 edge-tts：打开「Git Bash」（你平时 push 用的那个黑窗口），粘贴下面这行回车：
   ```
   pip install edge-tts
   ```
   看到 "Successfully installed edge-tts" 就成功了。（如果提示找不到 pip，把 `pip` 换成 `pip3` 再试。）

## 第二步：生成音频（每次加新词后跑一次）
1. 在 Git Bash 里，先进入你存放工作台代码的文件夹（就是平时敲 git 命令那个目录，里面要有 `scripts/` 子目录）。
2. 粘贴运行：
   ```
   python scripts/gen_vn_audio.py
   ```
   （如果提示找不到 python 命令，换成 `py scripts/gen_vn_audio.py` 或 `python3 scripts/gen_vn_audio.py` 试。）
3. 它会自动：
   - 跳过已经有的声音文件（不会重复录）；
   - 给**新增的**每个词录制一个 `NX_xxx.mp3` 到 `audio/vn/` 文件夹；
   - 屏幕滚动显示 `[OK] ...` 或 `[跳过] ...`，最后出现「完成！成功 xxx，失败 0」就大功告成。
4. 如果个别词显示「[失败]」，多半是当时网络不稳，重跑一次脚本即可（已成功的会自动跳过）。

## 第三步：像往常一样发布
```
git add -A
git commit -m "越南语新词发音（修正词音错位）"
git push
```
⚠️ **这里必须用 `git add -A`（不是 `git add .`）**：脚本重新生成时会先删掉旧的 `NX_*.mp3`，只有 `-A` 才会把"本地已删除的旧文件"同步到 GitHub 一起删掉。如果用 `git add .`，GitHub 上那些旧的错位文件还在，网页可能仍加载到错误的旧发音。
手机上把工作台**划掉重开**（别删主屏图标，删了数据就没了），新词就有声音啦。

## 常见问题
- 问：旧词的声音要不要重新生成？
  答：不用。脚本只给新增词（NX_ 开头）生成，旧的声音文件原封不动，互不干扰。
- 问：跑脚本要联网吗？
  答：要，因为它要去微软服务器录声音。录完后平时用 App 听是不需要联网的（mp3 已存在你手机里）。
- 问：我只加了几个词，也要跑整个脚本吗？
  答：是的，但脚本很聪明，已有的会秒跳过，只录新增的那几个，很快。
