## 选题灵感模块「总是离线兜底 / 立即刷新没反应」修复
- **根因**：`js/app.js` 的 `loadDaily()` 写了死规矩 `j.date === todayStr()`（文件日期必须正好是今天才算数）。`data/daily-ideas.json` 由「每日9点·热点选题灵感」自动化生成，但云端自动化写不到用户本地/线上文件，文件停在 `2026-07-27`；今天 07-28 时日期不匹配 → 被当成过期 → 强制退回 `localDaily()` 并显示「离线兜底」。而「立即刷新」只是把同一份 07-27 文件重读一遍 → 仍不匹配 → 还是兜底版 → 用户看着「一点没变」。
- **修复（js/app.js）**：
  1. `loadDaily()` 去掉严格的日期相等判断，改为「只要文件有效（有 items 数组且非空）就用」；
  2. `localDaily(seed)` 支持传时间种子；`renderDaily(fresh)` 新增参数——点「立即刷新」时用 `Date.now()` 种子重抽一批，每次都换新的；进入时优先用每日文件，没有再用本地灵感库；
  3. 元信息标签：过期文件显示「非今日，点立即刷新换一批」而非「离线兜底」；刷新提示改为「已换一批新灵感」。
  4. 重新生成 `data/daily-ideas.json`（date=2026-07-28，10 条按用户人设/季节写的选题），让打开即见当日内容。
- **未改**：「热点榜」模块本就无此日期死规矩（用 `loadDailyHot` 有效即用），不受影响。
- index.html 版本号 `?v=8` → `?v=9`（手机须划掉重开才加载新版）。
- **待办**：用户需 `git add/commit/push`；手机划掉 PWA 重开查看。沙箱 Bash 本时段持续抽风（node/python 均空返回），已用 Read 肉眼核对改动与 JSON 完整性，未能跑 node --check。

## 英语学习模块「未捕获错误」弹窗频繁弹出修复
- **现象**：用户在英语学习模块点开任意一篇文章后，经常弹出 `⚠️ 未捕获错误` 提示框（含 app.js:1883:39 / renderList 行号）。
- **根因**：`renderDetail()` 内有两处调用 `renderList()`：
  1. 第 1905 行：进入文章详情后，异步 IIFE 记录"已听次数"完毕后调 `renderList()` 刷新列表——但此时 `view.innerHTML` 已被替换为详情页，`#artList` 元素不存在 → `$('#artList')` 返回 null → 对 null 操作报错。
  2. 第 1975 行：「重置进度」按钮 handler 里也调了 `renderList()`——同样在详情页上下文中，`#artList` 不存在 → 同样炸。
  3. `renderList()` 本身无防御：`dailyEn` 为 null 或 `$('#artList')` 找不到时直接崩溃。
- **修复（js/app.js）**：
  1. `renderList()` 开头加防御性守卫：`if (!list || !dailyEn || !dailyEn.articles) return;`（找不到元素或数据未就绪时静默返回，不炸）。
  2. 第 1905 行异步 IIFE 中去掉 `renderList()` 调用（只保留 DB 写入记录次数；列表不可见时无需刷新）。
  3. 第 1975 行「重置进度」handler 中去掉 `renderList()` 调用（同理）。
- index.html 版本号 `?v=9` → `?v=10`。
- **待办**：用户需 push；手机划掉 PWA 重开。

## 内容复盘模块升级（调研后）
- **调研结论**（公众号/短视频创作者验证好用）：①每条带「平台 + 表现评级」可横向比；②结构化数据（播放/赞/评/转/粉）可算趋势；③「找规律」自动汇总（最佳TOP/最差TOP/好文共性 vs 差文共性/下一步重点）是复盘最大价值；④日/周/月模板降低记录门槛。
- **原模块短板**：仅 标题+亮点/不足/数据/优化 四格 + 日期，纯记录、无汇总、无分析、无模板。
- **升级（js/app.js renderReview 整段重写 + css/style.css 加样式）**：
  1. 每条新增 平台(select) + 表现评级(爆款/良好/一般/较差/翻车) + 结构化数据(播放阅读/赞/评/转/粉 数字) → 卡片显示平台徽章+彩色评级徽章+数据行。
  2. 顶部 4 格统计：复盘条数 / 爆款数 / 平均评级 / 最佳平台。
  3. 「📊 智能复盘报告」：扫描全部复盘，生成 表现分布/最佳3条/待改进3条/平台分布/各平台爆款数/下次动作清单/一句话总结，可复制、可存为备忘。
  4. 「📝 套模板」：日/周/月复盘 三种预设，自动填好标题与引导字段。
  5. 平台筛选下拉。
- 旧数据兼容：`metrics` 缺失时 `metricsLine` 回退显示旧 `data` 字段；`rating` 缺省显「未评」、`platform` 缺省「其他」。
