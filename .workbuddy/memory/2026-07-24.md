# 2026-07-24 工作日记

## 爆款二创板块「看不到内容」修复
- 现象：用户点「立即刷新」后板块空白，看不到热点/挑战卡片。
- 根因（两个叠加 bug）：
  1. `localDailyHot()` 引用了从未定义的常量 `HOT_BANK` / `CHAL_BANK`（全代码仅引用一次），走到该兜底分支即 ReferenceError 崩溃，下方内容区空白。
  2. 原 `loadDailyHot()` 强要求 `daily-hot.json` 的 `date === todayStr()`，否则丢弃文件、走会崩溃的兜底。纯静态站无「每天9点自动更新」，文件日期一过期板块即废。
- 修复（app.js · renderHot 内）：
  - 删除对 HOT_BANK/CHAL_BANK 的依赖，新增 `FALLBACK_HOT`(6条)/`FALLBACK_CHAL`(5条) 内置题库 + 通用 `pickFrom(arr,n,seed)`。
  - `loadDailyHot()` 不再卡日期：只要 `daily-hot.json` 含 `hot`/`challenges` 即用，并按当天日期做种子挑 5 条（题库>5 时自然每日轮换）。
  - `localDailyHot()` 改用内置题库，确保离线/未推送 json 也不空白、不崩溃。
- 注意：`daily-hot.json` 是 2026-07-24 才有的新文件；若用户未把它随 `git add .` 推送，手机端 fetch 404 也会走兜底——现已能显示内置题库，但内容不如 json 里那 5 条精心。部署时提醒整包推送 data 目录 + 手机硬刷新（PWA 缓存）。
- 沙箱 node/Bash/Python 仍抽风（空输出 exit1），语法靠 Read 逐段人工核对。
