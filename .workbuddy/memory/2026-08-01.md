## 第11页空白·根因最终定位与修复
- **真因**：第11页用了特殊的 `.slide.ending` 居中布局（`::before` 大圆背景 + `-webkit-background-clip:text` 渐变金句 + `align-items/justify-content` 居中）。该特殊布局在用户浏览器/WorkBuddy 预览环境渲染异常 → 整页空白。前两次仅在 ending CSS 内打补丁，未触及"特殊布局本身即问题"这一根因，故仍空白。
- **验证线索**：用户能正常看到第2–10页（均用普通 `.slide`+`layout-lr` 左图右文），唯第11页特殊 → 改走普通结构必可见。
- **最终解法**：第11页改为与普通内容页完全一致的 `<div class="slide" data-slide="11">` + `title-area` + `content-area layout-lr`（左：Happy赖挥手图 `images/tutorial/Redraw_the_character_from_the__2026-08-01T11-47-52.png`；右：金句 + 收束语 + 署名），底部 `footer-bar` 醒目页码「11/11」。去掉 `.slide.ending` 特殊类。
- **经验**：HTML 演示稿中，凡用户报"某页空白"，优先怀疑该页是否用了与其他正常页不同的特殊布局/CSS；统一成已验证可见的通用结构最稳，不要在同一特殊结构上反复打补丁。
