1. **SW 离线缓存 key 不匹配（真 bug）**：sw.js 的 ASSETS 预缓存 `'./js/app.js'`（无 query），但 index.html 请求 `'js/app.js?v=49'`。离线时 `caches.match(req)` 默认区分 query，**匹配不上 → app.js 加载失败 → 离线可能白屏**。而"不联网可用"是工作台核心卖点。修复：`caches.match(req, { ignoreSearch: true })`，或预缓存 URL 带版本号。
