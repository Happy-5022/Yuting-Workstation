# 2026-08-29 新增「📝 公众号助手」模块

## 背景
玉婷：公众号主要分享"通过AI学到的知识技能"，但每天"写什么"发愁，且"每次写完都要重复调格式"。要求工作台加一个针对公众号写作的功能。

## 实现（renderGzh）
新增模块 key:'gzh' emoji:'📝' title:'公众号助手'，解决两痛点：
- **写什么**：①顶部"今天写啥"统计(想写/草稿中/已发布) + 🎲智能推荐(从选题池挑最早排期的一条直接开写；池空则按近30天各支柱发文数推荐最少的支柱) ②选题池(状态流水线 想写→草稿→已发布，可转状态/设预计发布日，近期排期列表) ③⚙可改"内容支柱"(默认 知识干货/工具实操/个人成长/反差小剧场/读者答疑，存 meta gzhPillars)。
- **格式**：④写文章：模板(干货长文/清单体/故事体/答疑体/空白)一键套骨架 + 轻量markdown(#大标题 ##小标题 **加粗** >引用 ---分隔线)实时预览 + ⚙格式预设(强调色/字号/结尾固定语，存 meta gzhFmt，默认结尾"微信搜『Happy赖』关注我"——公众号内可提IP名，安全) + 📋复制带格式(ClipboardItem text/html，降级execCommand) / 📋复制纯文本 + 💾存草稿 + 草稿列表重开。

## 数据/版本
- db.js STORES 加 'gzh'，DB_VERSION 8→9（onupgradeneeded 自动建表，旧数据不丢）。
- MODULES 数组加 gzh；app.js 备份 stores 列表加 'gzh'。
- index.html：app.js?v=47→v=48，db.js?v=24→v=25（强制手机刷新缓存）。
- node --check db.js / app.js 均通过。

# 2026-08-29 经期记录模块 参照美柚优化（renderPeriod 重写）

## 背景
玉婷要求经期记录"参照美柚"优化。原模块只有：记开始日+周期设置+下次预测+排卵期+历史列表。

## 调研美柚核心能力
日历视图彩色标注(经期/排卵期/易孕期)、多维记录(流量轻重/痛经程度/症状)、未来6个月预测表、周期健康报告(平均周期/规律度/异常提醒)。

## 实现（重写 renderPeriod）
- **📅 周期日历**：逐月网格，颜色图例；实经期(红●)/预测经期(红虚线○)/排卵日(紫✦)/易孕期(橙)。点某天弹记录弹窗。
- **多维记录弹窗**(自建 modal，promptForm 不支持多选)：流量(轻/中/重)、痛经(无/轻/中/重)、症状(腹痛/腰酸/胸胀/情绪波动/头痛/疲劳/其他 多选)、备注。记录写 period 仓库(flow/pain/symptoms/duration)。
- **顶部状态**：正在经期中(第X/共Y天) / 距离下次N天；排卵期。
- **📊 周期健康报告**：平均周期、平均经期、规律度(按周期波动算百分比→很规律/较规律/不规律)、周期范围、异常提醒(最近一次比上一次长/短≥7天给提示)。
- **🔮 未来预测**：未来3次预计经期区间 + 排卵期。
- **📜 历史**：每条显示流量/痛经/症状 chips。

## 数据/版本
- 无新仓库(period 仓库已有，keyPath id autoIncrement，新建不带id)。
- index.html：app.js?v=48→v=49（db.js 不变 v=25）。
- node --check db.js / app.js 均通过。

## 待办
- 用户尚未 git push（手机仍跑旧版 v48/未含本优化）。
- 旧 period 记录无 flow/pain/symptoms 字段，历史显示自动降级(只显示日期/备注)。
