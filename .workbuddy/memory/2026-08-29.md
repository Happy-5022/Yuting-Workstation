# 2026-08-29 新增「📝 公众号助手」模块

## 背景
玉婷：公众号主要分享"通过AI学到的知识技能"，但每天"写什么"发愁，且"每次写完都要重复调格式"。要求工作台加一个针对公众号写作的功能。

## 实现（renderGzh）
新增模块 key:'gzh' emoji:'📝' title:'公众号助手'，解决两痛点：
- **写什么**：①顶部"今天写啥"统计(想写/草稿中/已发布) + 🎲智能推荐(从选题池挑最早排期的一条直接开写；池空则按近30天各支柱发文数推荐最少的支柱) ②选题池(状态流水线 想写→草稿→已发布，可转状态/设预计发布日，近期排期列表) ③⚙可改"内容支柱"(默认 知识干货/工具实操/个人成长/反差小剧场/读者答疑，存 meta gzhPillars)。
- **格式**：④写文章：模板(干货长文/清单体/故事体/答疑体/空白)一键套骨架 + 轻量markdown(#大标题 ##小标题 **加粗** >引用 ---分隔线)实时预览 + ⚙格式预设(强调色/字号/结尾固定语，存 meta gzhFmt，默认结尾"微信搜『Happy赖』关注我"——公众号内可提IP名，安全) + 📋复制带格式(ClipboardItem text/html，降级execCommand) / 📋复制纯文本 + 💾存草稿 + 草稿列表重开。

## 数据/版本
- db.js STORES 加 'gzh'，DB_VERSION 8→9（onupgradeneeded 自动建表，旧数据不丢）。
- MODULES 数组加 gzh；app.js 备份 stores 列表加 'gzh'。
- index.html：app.js?v=47→v=48，db.js?v=24→v=25（强制手机刷新缓存）。
- node --check db.js / app.js 均通过。
